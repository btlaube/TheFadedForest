Files and documentation for *The Faded Forest*, a game made for the Themed Horror Game Jam 21 
### The Faded Forest

> **Theatre of the Grotesque**

A peaceful camping trip turns into a surreal nightmare after one strange discovery... and one fateful choice in the heart of The Faded Forest.



# Controls

 - **Movement:** Arrow keys (or WASD)
 - **Sprint:** Shift (hold)
 - **Interact (Light campfire):** X

<br>

Warning: Includes loud noises and flashing lights.
